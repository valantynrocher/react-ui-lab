# React UI Lab

🎯 A collection of advanced, reusable React components built with React, TypeScript and Material UI.

This project serves both as a learning playground and a professional-grade component library, focused on UI/UX quality, accessibility, and developer experience.

---

## 🚀 Features

- ✅ Fully typed with **TypeScript**
- 🎨 Built with **Material UI** and **CSS-in-JS** (`@emotion/styled`)
- 🔄 **Input handling** via `react-hook-form`
- ⚡ Fast development with **Vite**
- 📘 Fully documented using **Storybook**
- ♿ Focus on accessibility, keyboard interaction, and UX best practices

## 🛠 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/valentin/react-ui-lab.git
cd react-ui-lab
npm install
```

## Start the development server:

```bash
npm run dev
```

## 📘 Storybook

Launch the Storybook UI component catalog:

```bash
npm run storybook
```

Build Storybook for deployment:

```bash
npm run build-storybook
```

## 📦 Build (Vite)

To build the component library:

```bash
npm run build
```

Output will be in the dist/ folder.
